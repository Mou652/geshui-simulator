# 个税模拟器安卓版使用说明

安卓版个人所得税模拟器 App 用虚构数据演示年度筛选、收入纳税明细和工资薪金。需要获取演示版本时，请先核对机型和 Android 版本，再查看项目的[安卓安装与激活说明](https://geshui.moujc.cn/install_guide.html)。iPhone 截图和教程可作为操作参考，版本获取状态以安装说明为准。

1. 按[资料设置教程](../docs/guides/configure-demo-data.md)准备虚构姓名、单位、年度和月收入，再预览并保存。具体按钮以拿到的演示版本为准。
2. 从首页或「办&查」进入收入纳税明细查询，选择与示例一致的年度和所得类型。
3. 先看收入与预扣税额汇总，再打开相应月份核对单笔明细。[收入纳税明细教程](../docs/guides/income-details-demo.md)
