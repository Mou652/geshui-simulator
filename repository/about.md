# Mou652 个税模拟器项目说明

个税模拟器也称个人所得税模拟器 App，由 Mou652 维护。它使用本机虚构资料演示个人所得税 App 的年度查询、月度工资薪金和单笔收入纳税明细，适合教学和界面操作讲解。

| 项目 | 说明 |
| --- | --- |
| 可以演示什么 | 设置虚构姓名、任职单位、年度和月份，浏览演示收入汇总及月度记录 |
| Android（安卓） | 查看[安卓版说明](android.md)及公开安装与激活指南 |
| iPhone（iOS） | 查看[iPhone 版本与操作说明](../docs/ios.md)，向维护者确认适用版本和获取方式 |
| 数据来源 | 本机配置的虚构示例 |
| 仓库内容 | 项目说明、截图和教程。App 演示版本通过维护者提供的渠道获取 |

实际办税、查询个人真实记录或取得正式税务材料，请使用税务机关提供的渠道。页面中的演示数据和图像仅用于说明操作。
