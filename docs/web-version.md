# 个税模拟器网页版说明：现有预览与功能范围

> 目前这个网站提供个税模拟器介绍、图文教程和静态界面预览，没有在浏览器中编辑虚构资料或运行完整模拟器的功能。需要操作演示版本，请先确认手机平台与适用版本。

维护者：Mou652 · 资料核对：2026-11-05

本页用于虚构资料的非官方教学演示。不同平台的入口与功能以对应版本说明为准；演示画面不能作为真实收入、纳税或身份材料。

## 浏览器里可以做什么

无需登录即可阅读教程、查看截图和了解平台范围。页面里的演示图片是静态素材，不能点击图片完成查询或提交资料。

## 浏览器里不能做什么

本站没有税务账号登录、真实收入查询、在线申报或纳税记录开具，也没有可编辑的在线模拟数据表单。不要向任何声称代查的第三方提供账号或验证码。

## 需要交互演示时

向维护者说明安卓或 iPhone 机型、系统版本与演示目标，确认适用的手机演示版本。公开教程以现有 iPhone 操作为例。

## 常见问题

### 网页版能直接修改收入数字吗？

目前不能。本站提供静态介绍、截图和教程。

### 自然人电子税务局是这个网站吗？

不是。官方自然人电子税务局请通过税务机关公布的地址进入。
