# 个税演示工具怎么选？五项核对与小场景验证

本页用于虚构资料的非官方教学演示。不同平台的入口与功能以对应版本说明为准；演示画面不能作为真实收入、纳税或身份材料。

## 先排查任务是否匹配

真实办税、税额估算和界面教学需要不同工具。明确自己要交付的是实际业务结果、计算结果，还是可解释的演示素材。

## 按小场景试用

在确认适用版本后，用一家虚构单位、一个年度和少量月份，检查保存、查询、修改和返回等流程。不要仅凭宣传截图决定功能是否满足需求。

## 保留可维护的说明

核对版本号、设备要求和反馈渠道。制作教程时记录所用版本，后续入口变化后更新说明，不沿用已经失效的操作路径。

## 对照检查

| 判断项 | 需要确认的问题 |
| --- | --- |
| 数据来源 | 是否为虚构资料，是否需要真实账号 |
| 设备 | 是否支持你的机型和系统 |
| 配置 | 能否准备目标年度、单位与月份 |
| 素材 | 文字、滚动和声音是否适合交付 |
| 维护 | 版本说明和反馈渠道是否清楚 |

## 常见问题

### 宣传说支持安卓就能直接用吗？

仍需核对机型、系统及具体版本范围。

### 最先测试什么？

先测试一组简单示例从保存到查询的完整流程，再检查截图录屏效果。
