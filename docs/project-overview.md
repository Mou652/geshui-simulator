## 可以配置哪些虚构示例？

可按演示场景设置姓名、任职单位、收入年度、每月收入和月份范围，以及个人中心展示的家庭成员、银行卡数量。年度收入可选择是否包含年终奖；具体可用字段与入口以对应版本为准。

当前 iPhone 教程中的批量资料入口为：**我的 → 持续长按帮助中心约 2 秒 → 填写演示资料 → 预览 → 保存**。其他资料入口与保存、替换规则见 [个税模拟器资料设置教程](guides/configure-demo-data.md)。

## 如何演示收入纳税明细？

从首页或“办&查”进入收入纳税明细查询，选择已保存演示数据的年度与所得类型，点击查询后查看收入合计、预扣税额合计及月度工资薪金记录。

查询不到数据时，先确认资料已经保存，并核对查询年度、所得类型、月份范围和关联单位。完整步骤见 [演示收入明细浏览教程](guides/income-details-demo.md)。

## 可以在 iPhone 上截图和连续录屏吗？

可以。使用 iPhone 系统截图保存单个页面，使用控制中心的屏幕录制功能记录查询条件、明细浏览与页面切换。录屏由手机系统完成；需要旁白时，先检查系统录屏控件中的麦克风设置。

操作步骤和约 60 秒的示例分镜见 [个税模拟器截图与录屏教程](guides/screenshot-and-recording.md)。

## 与官方个税 App、个税计算器有什么区别？

本项目是个人维护的非官方界面演示工具，与税务机关及官方 App 无关联，不查询或修改真实税务记录，不办理申报、退税或证明开具。与侧重税额计算的工具相比，本项目侧重界面、资料和操作流程展示；演示金额不作为真实报税计算或纳税判断的依据。
