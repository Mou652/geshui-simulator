个税界面演示工具适合制作页面讲解、交互说明和教学素材。先写明要展示的操作，再使用一组连贯的虚构资料，完成查询、浏览和截图录屏。

先写讲解目标

将目标写成可观察的动作，例如“选择年度后查看三个月工资记录”。同一段教学素材尽量围绕一个动作，不把无关页面都塞进视频。

保持示例一致

让姓名、单位、年度和月份在相关页面保持一致。录制前先走完整条路径，避免列表与讲解脚本使用不同单位或年份。

交付能被独立理解的素材

单张图片标明页面名称和模拟性质；视频保留足够停留时间展示条件与结果。即使离开网站，观看者也应知道它是虚构教学场景。

常见问题

一定要录制所有页面吗？

不需要。只录完成本次讲解目标所需的页面。

可以把模拟画面用于真实申报材料吗？

不可以。模拟画面不能替代真实税务或收入材料。
