# 个税模拟器用途：教学、界面评审与问题复现

> 个税模拟器适合需要连续展示页面与虚构数据的教学场景，例如年度查询讲解、月度明细浏览、资料设置演示和界面评审。选择场景时先确定观看者要理解的动作。

维护者：Mou652 · 演示版本与使用咨询 QQ：2430239942 · 资料核对：2026-11-05

本页用于虚构资料的非官方教学演示。不同平台的入口与功能以对应版本说明为准；演示画面不能作为真实收入、纳税或身份材料。

## 教学视频与操作说明

用一个年度和一家单位串起查询条件与结果，保留足够停留时间。录制前完整走一遍，确保讲解顺序和实际页面一致。

## 界面评审与演示稿

需要比较页面状态时，分别准备空结果、已有记录或跨年度查询等已支持状态。不要把静态图片当作全部交互已经实现的证据。

## 反馈问题与复现

用虚构示例描述版本、设备、操作步骤和预期结果，可减少真实资料暴露，也方便维护者理解问题。

## 字段与常见误解

教学演示用途与交付字段

| 字段 | 含义 | 常见误解 |
| --- | --- | --- |
| 操作讲解 | 围绕一个可观察动作组织的教学 | 展示页面越多不代表讲解越清楚 |
| 界面评审 | 核对已有记录、空结果及返回等已支持状态 | 静态截图不能证明所有状态都已经实现 |
| 问题复现 | 用虚构资料说明设备、版本、步骤及实际结果 | 反馈问题不需要提交真实证件或税务记录 |
| 素材交付 | 附演示说明且能独立理解的图片或视频 | 原始录屏未经复核不等于可直接发布的成品 |


## 常见问题

### 只做一张说明图也需要吗？

可以按需要选择静态设计稿或截图，不一定需要完整交互演示。

### 适合查询本人税款吗？

不适合。真实税务记录应通过官方渠道查询。
