浏览器里可以做什么

无需登录即可阅读教程、查看截图和了解平台范围。页面里的演示图片是静态素材，不能点击图片完成查询或提交资料。

浏览器里不能做什么

本站没有税务账号登录、真实收入查询、在线申报或纳税记录开具，也没有可编辑的在线模拟数据表单。不要向任何声称代查的第三方提供账号或验证码。

需要交互演示时

向维护者说明安卓或 iPhone 机型、系统版本与演示目标，确认适用的手机演示版本。公开教程以现有 iPhone 操作为例。
