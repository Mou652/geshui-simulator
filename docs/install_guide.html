02 / FOUR SIMPLE STEPS

准备好资料，开始演示。

以下是 GitHub 中的历史演示截图，用于了解界面。当前购买版本仅支持安卓，暂不支持 iOS；示例均使用虚构资料。

01

配置虚构姓名与单位

从「我的」进入对应版本的资料设置入口，填写演示姓名与任职单位，先准备一个简单场景。

查看资料设置教程 →
02

设置年度、月份与收入

选择要演示的年度与月份，填写示例收入等内容。预览并确认年份、单位与金额后，保存资料。

了解年度与收入配置 →
03

保存并核对收入明细

从首页进入收入纳税明细，选择已保存数据的年度与对应所得类型，核对收入合计和月度记录。

查看收入明细教程 →
04

截图，或录一段操作

用手机系统截图保存单页画面，或开启屏幕录制，串联年度选择、查询与明细浏览。

查看截图与录屏教程 →
