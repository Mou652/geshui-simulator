# 个税界面演示工具：从讲解目标到教学素材

> 做个税 App 界面教学时，先定一个讲解目标，例如「找到某年度的工资薪金明细」。用同一组虚构记录演示筛选、看汇总和打开详情，截图用于标出入口，录屏用于交代操作顺序。

本页用于虚构资料的非官方教学演示。不同平台的入口与功能以对应版本说明为准；演示画面不能作为真实收入、纳税或身份材料。

## 先写讲解目标

将目标写成可观察的动作，例如“选择年度后查看三个月工资记录”。同一段教学素材尽量围绕一个动作，不把无关页面都塞进视频。

## 保持示例一致

让姓名、单位、年度和月份在相关页面保持一致。录制前先走完整条路径，避免列表与讲解脚本使用不同单位或年份。

## 交付能被独立理解的素材

单张图片标明页面名称和模拟性质；视频保留足够停留时间展示条件与结果。即使离开网站，观看者也应知道它是虚构教学场景。

## 一段收入明细教学录屏怎么安排

开头停在年度和所得类型筛选页，让观众看清查询范围。结果页先展示收入合计，再向下滚动到月度列表，并点开一笔记录核对单位和月份。录完回放一次，检查年份、金额及模拟演示标识能否看清。

## 字段与常见误解

界面教学素材准备字段

| 字段 | 含义 | 常见误解 |
| --- | --- | --- |
| 讲解目标 | 观看者需要理解的具体操作 | 一段视频不需要展示所有无关页面 |
| 示例上下文 | 相关页面一致的虚构姓名、单位与年度 | 每张画面单独正确不代表连续操作前后一致 |
| 操作路径 | 录制前完整走过的查询与浏览步骤 | 静态图片不能证明全部交互可用 |
| 模拟标识 | 图片或视频内可独立看到的演示说明 | 只在网站文字中说明，素材转发后可能看不到 |


## 常见问题

### 一定要录制所有页面吗？

不需要。只录完成本次讲解目标所需的页面。

### 可以把模拟画面用于真实申报材料吗？

不可以。模拟画面不能替代真实税务或收入材料。
