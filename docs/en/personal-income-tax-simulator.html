China Personal Income Tax App Simulator

Geshui Simulator is an independent educational tool maintained by Mou652. It demonstrates how a Chinese individual income tax app organizes annual queries, salary income and monthly records. All records in the demo are fictional.

Follow an annual income query

  1. Prepare a fictional employer and example salary records for two or more months.
  2. Select a year and the salary income category to view the sample records.
  3. Compare the annual income total with the monthly rows. Open a row to review its example amount.

The income details guide in Chinese shows where these controls appear.

Android setup and iPhone references

The current public setup instructions cover Android installation and activation. The iPhone tutorials document interface examples. Check the Android installation guide in Chinese for current availability.

Project and official tax services

The public GitHub repository contains documentation and interface screenshots. You can also read the Gitee mirror.

The demo cannot access real tax accounts, compute tax for filing, submit returns or issue official records. Use the official Chinese tax service for those tasks.
