按状态理解页面

查询前展示条件，查询后展示结果，进入详情后保留记录上下文。评审时分别检查空结果、已有记录和返回查询等状态，而非只看单张截图。

数据关系决定是否讲得通

单位、年度、月份和金额应在相关页面一致。若页面展示来自虚构示例，应在素材中明示，不能通过相似界面暗示真实记录来源。

公开资料能支持什么

本仓库提供教学说明与截图，可用于了解演示结构，但没有可构建的 App 源码。实现方式、覆盖页面及交互能力不能仅从截图推断。
