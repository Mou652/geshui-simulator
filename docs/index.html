Mou652 个税模拟器（Geshui Simulator，也称个人所得税模拟器）是面向苹果 iPhone / iOS 的非官方个税界面教学演示工具。可配置本机虚构示例数据，浏览演示收入明细，并配合手机系统截图和屏幕录制制作教学、操作讲解与产品展示素材。

个人维护的非官方演示项目，与税务机关及官方 App 无关联。页面资料和金额用于模拟演示，不代表真实申报记录或纳税凭证。

个税模拟器中文使用教程

无需登录或下载即可阅读全文。按“了解版本 → 配置虚构示例 → 浏览本机演示明细 → 录制教学素材”的顺序准备。

首次使用前如何确认演示版本？

了解项目用途、适用设备和版本确认方式，再按指南准备演示。

如何配置虚构示例姓名、单位和金额？

查看资料入口，配置年度、月薪与月份范围，了解预览和保存规则。

如何浏览本机演示收入明细？

选择年度和所得类型，浏览收入合计、预扣税额及月度工资薪金记录。

个税模拟器怎么截图、怎么录屏？

用 iPhone 系统功能保存画面，参考约 60 秒的演示脚本完成连续录制。

可以用个税模拟器演示什么？

虚构示例数据配置

设置虚构姓名、任职单位、年度收入与月份范围，准备不同的讲解场景。预览后保存，再回到查询页核对演示效果。

年度与月度示例记录

从首页或“办&查”进入收入纳税明细，选择已保存数据的年度与所得类型，展示收入汇总、预扣税额及月度记录。

页面截图与连续录屏

用系统截图呈现单页，用屏幕录制串联“资料设置 → 年度查询 → 明细浏览”的操作过程。适合个税 App 操作教学、收入纳税明细讲解与界面展示。

常见问题

首次使用前如何确认演示版本？

先阅读项目说明和设备准备指南。如需了解演示版本，向维护者说明设备与 iOS 版本，确认适用范围。本网站没有安装包下载链接。查看首次使用与版本说明指南。

可以配置哪些虚构示例？

可配置虚构示例姓名、演示单位、年度、月份和示例金额。个人中心的数量字段也仅用于本机展示，不需要真实家庭成员或银行账户。年度收入可选择是否包含年终奖，具体字段以对应版本为准。

可以在 iPhone 上截图和连续录屏吗？

可以。使用 iPhone 系统截图保存单页画面，使用控制中心的屏幕录制功能记录年度筛选、明细浏览和页面切换。

会查询或修改真实税务记录吗？

不会。项目使用本地虚构演示资料，与税务机关及官方 App 无关联，不连接官方税务系统，不办理申报、退税或证明开具。

与个税计算器有什么区别？

本项目侧重界面、资料与操作流程展示。演示金额不作为真实报税计算或纳税判断的依据。
