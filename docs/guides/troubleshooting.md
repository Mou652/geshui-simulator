# 个税模拟器常见问题：资料设置、收入明细查询与截图录屏

个税模拟器中查不到收入明细时，先检查演示资料是否保存，再核对年度、所得类型、月份和单位。找不到资料入口或录屏结果不符合预期时，可以按下面的操作顺序逐项排查。

本文适用于本项目的虚构数据演示。入口说明以当前公开的 iPhone 教程为例；安卓和其他版本先核对对应版本说明。使用咨询 **QQ：2430239942**。

## 先确认你使用的是哪个版本

确认项目维护者为 Mou652，并记录手机机型、Android 或 iOS 版本。反馈时说明是安卓还是 iPhone，以及问题出现在哪个页面；只有“个税打不开”或“查询没有数据”，往往不足以定位原因。

如果你要查询本人真实税务记录，应使用税务机关提供的正式渠道。本项目只显示本机保存的演示资料。

## 我的页面找不到资料设置入口怎么办？

当前 iPhone 教程中的批量资料入口是“我的 → 持续长按帮助中心约 2 秒”。轻点可能进入帮助页面，需要返回后持续按住。查看或逐条编辑已有资料，可核对“我的 → 关于&更新 → 资料设置”入口。

不同版本的按钮位置可能有差异。先按 [资料设置教程](configure-demo-data.md) 对照入口；仍不一致时，反馈设备和版本，以及实际看到的按钮名称。

## 收入纳税明细为什么查询不到数据？

按下面四项检查，不需要反复点击查询：

1. **保存状态**：表单里填写过资料、打开过预览，都不等于已保存。先完成保存。
2. **纳税年度**：查询页选择的年份，应与本机演示资料的年度一致。
3. **所得类型**：演示工资记录时，选择“工资薪金”；勾选其他类型不会生成相应记录。
4. **月份和单位**：核对已配置的月份范围，以及该年度关联的演示任职单位。

例如，本机保存的是某一年度 1—3 月的演示工资，就选择同一年度和工资薪金，检查这三个月的记录。完整路径见 [个税模拟器收入明细查询教程](income-details-demo.md)。

## 修改姓名、单位或金额后，为什么还是旧画面？

先确认修改已保存，再退出当前结果页，重新选择年度和所得类型查询。个人中心与收入列表展示不同内容：修改姓名后应检查个人中心；修改年度收入后应检查对应年份的月度记录。

准备截图或录屏前，先核对显示的年份、演示单位和月份。反馈时明确说明“预览正确但保存后不一致”，或“保存后没有重新查询”，比只描述“没有变化”更容易排查。

## 为什么每个月的演示收入不完全一样？

年度配置可能在设定月薪附近生成浮动的示例金额。月薪输入、预览记录和保存后的月度结果是不同阶段，检查时以最终保存并重新查询的记录为准。

如果讲解需要固定的数值，先检查对应版本是否支持编辑单条演示记录，并在保存后核对。相关步骤和保存说明见 [年度、月薪与月份配置](configure-demo-data.md)。

## 个税截图和录屏应该先准备什么？

先确定要展示查询页、月度列表还是个人中心。使用同一组虚构示例资料，核对演示姓名、单位、年份和金额，再用手机系统功能截图或录屏。

录制时先短录一段，检查页面文字、滚动速度和声音。需要旁白时检查系统录屏麦克风设置。iPhone 的操作与演示分镜见 [个税截图录屏教程](screenshot-and-recording.md)；安卓设备按本机系统提供的截图、录屏入口操作。

## 怎样反馈问题更容易定位？

可以按下面的格式描述，不需要提供真实身份、账户或税务资料：

| 信息 | 示例写法 |
| --- | --- |
| 设备与系统 | iPhone 或安卓，具体机型和系统版本 |
| 当前页面 | 我的、资料设置、年度查询或收入纳税明细 |
| 操作步骤 | 配置演示年度并保存，再进入查询页 |
| 预期结果 | 展示选定年度的 1—3 月虚构工资记录 |
| 实际结果 | 没有记录、月份不完整、单位不一致等 |
| 已检查项目 | 保存状态、年度、所得类型、月份和单位 |

项目反馈也可以通过 [GitHub Issues](https://github.com/Mou652/geshui-simulator/issues) 提交。附图只使用本机虚构示例，并保留“模拟演示”的说明。
