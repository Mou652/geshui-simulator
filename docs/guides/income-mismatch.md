# 个税App收入明细和实际工资对不上怎么办

> 收入明细与到账工资不同，先检查税前与实发口径、所属期间、单位以及奖金或补发等项目，再向扣缴单位逐项核实。不要直接把银行到账额填回税务记录。

维护者：Mou652 · 演示版本与使用咨询 QQ：2430239942 · 资料核对：2026-11-05

本页整理官方渠道的公开操作信息。实际业务以当前官方系统和适用政策为准；本站不是税务机关网站，不接收真实税务账号，不在本站办理申报。

## 操作与核对步骤

1. **对齐年度与期间**：确认单位、所得类型和收入期间相同。
2. **列出字段对照**：将工资条、到账和官方记录分别列出，不混用金额。
3. **向单位核实差额**：带着具体项目询问，必要时按官方途径处理。

## 把比较范围对齐

确认比较的是同一单位、同一收入期间及同一笔业务。银行到账日、工资条期间和税务记录期间可能需要结合发放安排核实。

## 列出差异而不是猜原因

分别记录工资条应发、实发、扣款和系统显示字段。报销、补贴、奖金等是否计入，应向单位询问具体口径，不能一概推断。

## 模拟器核对的是本机示例

教学时输入的月薪与最终每月示例可能不同，年度配置可产生浮动。请以保存后重新查询的结果核对，不把演示差异当作真实申报问题。

## 字段与常见误解

收入与工资差异核对字段

| 字段 | 含义 | 常见误解 |
| --- | --- | --- |
| 应发与实发 | 工资条上不同口径的金额 | 系统收入不能不加区分地与银行到账额比较 |
| 单位与所属期间 | 确认是否在比较同一单位、同笔收入和同一期间 | 到账月份与记录期间不能默认完全相同 |
| 奖金、补发与扣款 | 需要向单位核实是否计入的具体项目 | 差额不能未经核实就归因于某一项扣款 |
| 演示月薪与结果 | 模拟配置参数及保存后实际展示的月度示例 | 配置可产生浮动，不能把示例差异当真实申报错误 |


## 常见问题

### 工资到账少于收入明细就是错了吗？

不能仅凭这一点认定错误，应先核对税前、实发及扣款等口径。

### 可以在模拟器里修正真实工资记录吗？

不能。模拟器编辑只影响本机虚构示例。
