打开在线演示工具 · 产品介绍与预览

先分清预览和导出

预览用于检查文字、日期和版式。宣传截图上的原有预览提示会保留，它不代表实际授权文件的最终效果。工具的 PDF 导出由服务端验证授权后生成，不能通过隐藏页面水印来获得导出权限。

导出前完成核对

首次导出前重点核对姓名、证件号码、单位及公章名称，随后检查岗位、任职和开具日期、公章外观及位置。核心资料会绑定到这份证明；不要把生成后的修改额度当作更换证明主体的次数。

下载中断时怎样处理

保持原浏览器和原资料，重新发起相同版本的下载。服务端已生成的同一版本不会再次增加版本计数；生成失败不计版本。如果修改了资料，可能被识别为新的版本，请先查看剩余额度。

文件打开和打印检查

文件下载完成后，用可打开 PDF 的应用查看中文是否完整、是否为单页，以及文字和公章是否在页面范围内。手机的下载位置和打开方式随系统、浏览器不同而变化，以设备提示为准；打印前还应核对纸张和缩放设置。

期限结束后保留什么

纠错期从首次成功生成 PDF 开始计算，固定24小时。到期后不能再导出或重新下载；已经下载的文件可以保留。请提前保存需要的版本，浏览器历史记录不是文件备份。

常见问题

授权 PDF 还带产品水印吗？

正常激活并通过服务端授权校验后，导出的 PDF 不叠加产品水印。预览仍保留预览提示。

同样的资料再下载一次，会消耗修改次数吗？

同一版本在原有效期内重复下载不增加次数，也不会延长24小时有效期。更改资料形成新版本时，受最多3个版本的额度限制。
