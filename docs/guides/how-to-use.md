# 个税模拟器怎么用？四步完整教程

> 使用个税模拟器可按四步准备：确认设备版本、配置并保存虚构资料、查询本机演示明细、使用系统截图或录屏。每一步先检查结果，再进入下一步。

维护者：Mou652 · 演示版本与使用咨询 QQ：2430239942 · 资料核对：2026-11-05

本页用于虚构资料的非官方教学演示。不同平台的入口与功能以对应版本说明为准；演示画面不能作为真实收入、纳税或身份材料。

## 操作与核对步骤

1. **确认适用版本**：说明设备与系统，按对应说明打开演示版本。
2. **保存虚构资料**：配置姓名、单位、年度和月份，预览后保存。
3. **浏览本机明细**：选择对应年度和所得类型，核对汇总与月度记录。
4. **截图或录屏**：使用手机系统功能保存画面，检查最终素材。

## 先把演示范围缩小

第一次用一家虚构单位、一个年度和 1—3 个月份即可。这样可以逐条核对，不需要一次生成多年度、多单位的大量数据。

## 保存是资料与查询的连接点

表单输入和预览不代表已应用。保存后再进入查询页，选择同一年度和所得类型；修改后应退出旧结果页重新查询。

## 发布素材前检查说明

核对示例姓名、单位、月份、金额，以及画面中“非官方模拟演示”的标识。原始录屏和对外版本分别保存，便于发现问题后重新导出。

## 字段与常见误解

模拟器四步使用检查项

| 字段 | 含义 | 常见误解 |
| --- | --- | --- |
| 设备版本 | 先确认手机平台、机型与系统要求 | 其他设备的入口说明不一定适用本机 |
| 预览与保存 | 检查虚构资料后将示例应用到本机 | 表单填完或看到预览不代表已经保存 |
| 查询条件 | 与已保存资料对应的年度和所得类型 | 切换条件不会自动生成缺少的演示数据 |
| 截图与录屏 | 用系统功能记录已核对的教学画面 | 原始素材不能未经检查就作为对外版本 |

## 常见问题

### 只打开预览就可以去查了吗？

应先完成保存，再到对应年度查询。

### 画面必须和网站截图金额相同吗？

不需要。网站图片是一组示例，你的结果取决于本机保存的虚构资料。
