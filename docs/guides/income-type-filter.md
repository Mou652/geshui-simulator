# 个税App所得类型怎么筛选（工资薪金/劳务报酬等）

> 收入纳税明细可以按页面提供的所得类型筛选。核对工资时选择工资薪金，核对其他报酬时按对应类型查看，避免把不同所得项目的记录混为一组。

## 操作与核对步骤

1. **选择目标年度**：先固定要核对的年度，便于比较结果。
2. **选择所得类型**：依当前页面勾选目标类型，记录是否同时选了其他项目。
3. **查询并核对**：结合单位和所属期间查看记录，存在分类疑问时先核实。

## 先按收入性质核对

工资薪金、劳务报酬、稿酬和特许权使用费是不同的所得项目。遇到分类疑问，应向支付或扣缴单位核实具体业务，不凭到账金额判断类型。

## 汇总会受筛选范围影响

阅读收入合计时同时记录所选年度和所得类型。单一类型的查询结果与包含其他类型的结果，不宜直接比较。

## 模拟器筛选不等于新增数据

查询页存在某个选项，不代表演示版本支持配置该类型记录。先检查已保存资料和版本说明，不把空结果当作程序丢失数据。

## 常见问题

### 勾选劳务报酬就能生成劳务记录吗？

不能。筛选只决定查询范围，不会生成官方记录或本机示例。

### 为什么切换类型后合计变了？

应先核对筛选范围是否变化，再比较同一范围内的明细。
