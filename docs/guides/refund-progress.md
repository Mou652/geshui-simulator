# 个税App怎么查退税进度

> 查询退税进度，可在官方个人所得税 App 的申报记录中找到对应年度已完成的汇算记录，再查看退税记录。审核、国库处理与到账是不同环节，不能承诺固定天数。

维护者：Mou652 · 演示版本与使用咨询 QQ：2430239942 · 资料核对：2026-11-05

本页整理官方渠道的公开操作信息。实际业务以当前官方系统和适用政策为准；本站不是税务机关网站，不接收真实税务账号，不在本站办理申报。

## 操作与核对步骤

1. **打开对应申报记录**：在“办&查”相关申报记录中选择目标年度的汇算记录。
2. **查看退税记录**：打开详情中的退税记录，核对当前状态与官方提示。
3. **按原因处理**：需要补充资料或更换账户时，依该申请提供的处理方式操作。

## 先找对年度与申请

根据申报记录确认是哪一年度的汇算，以及退税申请是否已经提交。只有申报完成，不一定等于退税已经处理完成。

## 按当前状态阅读提示

审核中与国库处理中属于不同阶段；审核不通过或退库失败时，应阅读官方给出的原因和处理说明，不盲目重复提交。

## 银行卡异常需针对处理

退库失败可能涉及账户状态、账户类别或资料不符。按该笔申请的提示核对本人账户，不因为已添加新卡就假定原申请自动切换。

## 字段与常见误解

退税进度状态含义

| 字段 | 含义 | 常见误解 |
| --- | --- | --- |
| 税务审核中 | 税务机关正在审核退税申请 | 这一状态不等于税款已转入银行卡 |
| 税务审核不通过 | 需查看官方列明的原因并核实申报资料 | 不能不看原因就反复原样提交 |
| 国库处理中 | 申请已提交国库，正在按规定处理 | 不能据此承诺固定到账日期 |
| 国库退库失败 | 税款未能退到所选账户，需按提示核对银行卡 | 添加新卡不代表原申请已自动改用新卡 |
| 国库处理完成 | 官方显示退税成功，仍应核对所选账户到账情况 | 不能只看其他年度的记录判断本次进度 |


## 常见问题

### 国库处理中代表已经到账吗？

不能直接等同，应继续查看最终状态并核对本人账户入账情况。

### 能保证几天到账吗？

不能。本页不承诺审核或退库时长，以官方处理结果为准。
