# 个税App密码忘了怎么办？找回流程

> 忘记官方个人所得税 App 密码时，从登录页进入“找回密码”，核对身份后选择当前可用的验证方式。无法通过在线验证时，向税务机关确认办税服务厅办理途径。

维护者：Mou652 · 演示版本与使用咨询 QQ：2430239942 · 资料核对：2026-11-05

本页整理官方渠道的公开操作信息。实际业务以当前官方系统和适用政策为准；本站不是税务机关网站，不接收真实税务账号，不在本站办理申报。

## 操作与核对步骤

1. **打开找回密码**：在官方登录页进入对应入口。
2. **完成本人验证**：依当前页面选择可用方式并核对身份资料。
3. **设置新密码**：验证通过后按密码规则设置，再确认能正常登录。

## 只在官方页面重置

通过已确认来源的 App 或自然人电子税务局操作。不要把验证码、银行卡验证资料或新密码发给第三方代办。

## 按当前可用方式验证

税务机关指引列有已绑定手机号或本人银行卡验证等方式，实际选项以页面为准。不能收验证码时，先查看是否有其他本人可用的验证方式。

## 无法在线完成时

保留不含敏感资料的错误描述，向官方帮助渠道咨询。需要去服务厅时，先确认有效身份证件和当地具体要求，避免反复尝试不适用的流程。

## 常见问题

### 大厅注册码等于密码重置方式吗？

不能直接等同。应以当前官方找回密码流程和服务厅说明为准。

### 维护者能帮我重置税务账号吗？

不能。本项目维护者不管理官方税务账号。
