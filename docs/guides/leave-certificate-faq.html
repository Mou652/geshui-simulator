填错资料怎么修正

首次导出前可回到表单核对。首次成功生成后，日期、岗位和公章外观等可在期限和剩余版本内修正；核心资料绑定后出现误填，请联系维护者。不要通过清理缓存或重复输入已用码尝试重置授权。

为什么激活或下载失败

先检查是否使用离职证明专用激活码，再检查授权是否过期、是否仍在原浏览器、是否修改了绑定资料。网络或服务异常时先保留当前页面和错误提示；咨询时不需要公开完整激活码、证件号码或生成文件。

示例资料保存在哪里

浏览器草稿留在本机。预览请求会将填写资料发送到服务端生成图片，预览不保存；授权 PDF 在纠错期内保存在服务端私有目录，结束后由清理任务删除。服务器仍需在生成期间处理输入，因此不要把工具宣传为所有数据都不离开浏览器。

公开资料和服务源码有什么区别

GitHub 与 Gitee 仓库公开产品介绍、截图和实现说明，不包含私有服务端、激活数据或可构建的个税 App 源码。公开文档的许可证不等于所有应用和服务均开源。
