# 个税完税证明与纳税记录：先确认期间和材料

> 先按税款所属期确认材料名称：2019 年及以后个人所得税缴退税情况通常开具《纳税记录》，此前按相应规则办理《税收完税证明》。不要把两类材料混为一谈。

## 操作与核对步骤

1. **核对税款所属期**：确认材料对应 2019 年及以后，还是更早期间。
2. **确认准确材料名称**：向接收方与税务机关核对需要纳税记录还是完税证明。
3. **通过适用官方渠道申请**：线上入口不适用时，先咨询再准备线下材料。

## 为什么名称不同

税务机关对 2019 年前后的个人所得税证明形式作了调整。日常口语中的“完税证明”不一定等于办事表单里实际要求的材料，应先确认准确名称。

## 线上与线下怎样选择

需要纳税记录时可查看官方 App 或自然人电子税务局入口。历史期间、身份验证或材料要求无法在线满足时，向主管税务机关确认线下办理所需资料。

## 不要用图片代替证明

无论走哪种渠道，都应保留官方生成或出具的材料。模拟截图、手工排版或修改金额不能成为正式纳税证明。

## 字段与常见误解

纳税记录与完税证明材料字段

| 字段 | 含义 | 常见误解 |
| --- | --- | --- |
| 税款所属期 | 选择材料前需要先确认的历史时间范围 | 材料名称不能只按申请当天的年份决定 |
| 纳税记录 | 2019 年及以后个人所得税缴退税情况的相关证明形式 | 日常口语中的完税证明不一定是表单要求的名称 |
| 税收完税证明 | 历史期间按相应规则办理的证明材料 | 不同历史期间的材料名称和办理要求不能直接通用 |
| 材料接收要求 | 接收方明确要求的期间与文件形式 | 演示截图不能满足正式证明材料要求 |


## 常见问题

### 2019 年以后的材料还都叫完税证明吗？

税务机关已将相关个人所得税文书式证明调整为纳税记录，应按实际材料名称办理。

### 线上办不成就能用截图替代吗？

不能。应向主管税务机关确认适用的正式办理方式。
