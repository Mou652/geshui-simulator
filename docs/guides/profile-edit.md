# 个税App个人信息怎么修改

> 修改官方个税 App 个人信息前，先区分联系方式等可编辑资料与姓名、证件等身份资料，再按当前页面及税务机关要求办理。不能把模拟器里的资料编辑流程用于真实身份信息变更。

维护者：Mou652 · 资料核对：2026-11-05

本页整理官方渠道的公开操作信息。实际业务以当前官方系统和适用政策为准；本站不是税务机关网站，不接收真实税务账号，不在本站办理申报。

## 操作与核对步骤

1. **确认需要变更的字段**：区分联系方式与身份资料，记录当前差异。
2. **查看官方可用入口**：按当前 App 提供的方式核对验证与材料要求。
3. **核验更新结果**：办理后重新查看资料，有差异继续向官方渠道确认。

## 先看字段是否可编辑

不同身份类型和业务情形，允许在线变更的字段可能不同。页面没有编辑入口时，不要通过其他字段代填，先查询官方说明。

## 身份资料变化怎样处理

核对本人有效证件与系统信息，向官方渠道确认是否可在线更正或需要服务厅核验。不要将密码找回、手机号更换和身份资料更正混为同一流程。

## 演示资料由本机维护

在个税模拟器中，虚构姓名和单位用于教学画面，修改后保存并检查相应页面。它不会更新任何官方身份档案。

## 常见问题

### 姓名和证件号一定能在 App 里直接改吗？

不能作统一保证，要按当前官方渠道和具体身份情形确认。

### 改了模拟器姓名，真实账号也会变吗？

不会。两者数据互不相通。
